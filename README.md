# Viral Quest

This project contains a simple Roblox script for a +1 Train to Titan Simulator game. The script is designed to be easy to code and has the potential to go viral. It includes player and titan scripts, shared constants, and utility functions to handle player and titan properties, controls, and data cleanup.

## Install

1. Clone the repository to your local machine.
2. Open Roblox Studio.
3. Click on "File" and select "Open Model".
4. Navigate to the cloned repository and open the `Viral Quest.rbxl` file.
5. The project files should now be available in the Roblox Studio explorer.

## Use

1. Open the `Viral Quest.rbxl` file in Roblox Studio.
2. Navigate to the `ServerScriptService` in the explorer.
3. Create a new script and name it `PlayerScript`.
4. Copy the contents of `src/PlayerScript.server.lua` and paste it into the `PlayerScript` script.
5. Create another new script and name it `TitanScript`.
6. Copy the contents of `src/TitanScript.server.lua` and paste it into the `TitanScript` script.
7. Navigate to the `ReplicatedStorage` in the explorer.
8. Create a new folder and name it `Shared`.
9. Inside the `Shared` folder, create two new scripts: `Constants` and `Utils`.
10. Copy the contents of `src/Shared/Constants.lua` and paste it into the `Constants` script.
11. Copy the contents of `src/Shared/Utils.lua` and paste it into the `Utils` script.
12. Save and publish the game.
